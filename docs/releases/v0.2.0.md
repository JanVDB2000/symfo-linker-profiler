# SymfoLinker v0.2.0

This release improves recovery when switching Composer packages and adds saved workspaces and link profiles.

## New

- Saved workspaces in Settings to reopen development roots quickly.
- Named link profiles that save package modes across a workspace, with a confirmation preview, backend validation and rollback of completed changes if a later switch fails.
- A backup journal recording package, project, installed version where available, timestamp and operation state.
- Explicit recovery in Health for interrupted swaps and broken links whose local checkout has disappeared.
- Restored workspace scans on startup, with a visible cache timestamp and an explicit Refresh action.

## Improved

- Restoring VENDOR verifies the backup first and preserves the exact original link for rollback, including broken links and Windows junctions.
- Status and container responses from previously selected projects are discarded.
- Git and container commands have deadlines; output collection also times out when descendants keep pipes open.
- Failed Docker/Podman detection is retried, and workspace Refresh resets engine detection.
- PHP service settings are written atomically under the development-root lock.
- Unrecognized, interrupted, lost and mismatched backups are surfaced; malformed journals are preserved.
- Settings uses a gear icon. New controls and messages support English, Dutch, French and German.
- CI includes cache and interaction tests, with additional recovery, profile rollback and process timeout coverage.

## Downloads

Choose the installer for your platform: Windows `.msi` or `.exe`, macOS `.dmg` for Apple silicon or Intel, or Linux `.AppImage`, `.deb` or `.rpm`.

Builds are unsigned. Windows SmartScreen and macOS Gatekeeper may warn on first launch; see the README for installation details. macOS `.app.tar.gz` files are update bundles, not installers.

Legacy backups without a journal remain marked Unrecognized. Profile rollback can itself fail if filesystem permissions or paths change during the operation; the error identifies the affected path and a fresh scan is required.
